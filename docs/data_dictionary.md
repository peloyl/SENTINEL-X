
# Data Dictionary
Time: seconds from first transaction. V1-V28: PCA-anonymized features (Kaggle creditcardfraud).
Amount: transaction amount. Class: 1=fraud, 0=legitimate (dataset label).
Derived: hour, log_amount, amount_z. NOT present in source: IP, device, geolocation, per-user 90-day history - marked UNAVAILABLE in UI.
Synthetic demo data mimics this schema only; it is simulated, not observed.
